# syntraceapp.github.io

Roten för GitHub Pages. Används för SynTrace:

- `index.html` skickar vidare till appen på `/SynTrace/app/`.
- `.well-known/assetlinks.json` (läggs till senare) behövs för att Android-appen på Google Play ska öppnas utan adressrad.
- `.nojekyll` gör att mappen `.well-known` publiceras.
